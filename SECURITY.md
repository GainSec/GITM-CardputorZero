# Security policy

## Supported version

Security fixes currently target the latest commit on `main` for the `0.1.x` line.

## Reporting a vulnerability

Report suspected vulnerabilities privately through the repository’s GitHub **Security** tab using a private vulnerability report. Do not include undisclosed vulnerability details, credentials, client data, captures, or device identifiers in a public issue.

Include the affected commit or package version, impact, prerequisites, and minimal reproduction steps. Reports about authorized testing are welcome; do not submit data obtained from systems or clients you were not authorized to test.

If private reporting is unavailable, open a public issue requesting a private contact channel without disclosing the vulnerability details.
