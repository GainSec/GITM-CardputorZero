# Security policy

## Supported version

Security fixes currently target the latest commit on `main` for the `0.2.1` line.

## Reporting a vulnerability

Report suspected vulnerabilities privately through the [repository’s GitHub Security tab](https://github.com/GainSec/GITM-CardputorZero/security) using a private vulnerability report. Do not include undisclosed vulnerability details, credentials, client data, captures, or device identifiers in a public issue.

Include the affected commit or package version, impact, prerequisites, and minimal reproduction steps. Reports about authorized testing are welcome; do not submit data obtained from systems or clients you were not authorized to test.

If private reporting is unavailable, open a public issue requesting a private contact channel without disclosing the vulnerability details.

The twelve pinned eMudhra lab profile keys are intentional public release material. Generated local/custom CA keys, exports and traffic evidence must remain private. Report changes to the trust, key-validation, helper-ownership or cleanup boundaries through the private channel above.
